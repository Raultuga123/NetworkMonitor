# NetworkMonitor

NetworkMonitor is a small desktop application I built in C# and WPF to practice networking concepts and create a useful tool for checking devices on a local network.

The application can ping an IP address or hostname and scan the local network to find devices that respond.

## Features

- Ping an IP address or hostname
- Display online/offline status
- Show response time in milliseconds
- Detect the local IPv4 address
- Scan the local network for active devices
- Scan multiple IP addresses asynchronously
- Automatically detect the local network prefix

## Built with

- C#
- .NET
- WPF
- XAML
- Visual Studio

## What I learned

While building this project, I practiced working with networking in C# and learned more about IP addresses, ping requests and local network scanning.

I also practiced asynchronous programming using `async`, `await`, `Task` and `Task.WhenAll`.

The interface was created with WPF and XAML.

## How to run

1. Clone or download the repository.
2. Open `NetworkMonitor.slnx` in Visual Studio.
3. Build and run the project.
4. Use the Ping section to test an IP address or hostname.
5. Use Scan Network to discover responding devices on your local network.
